# fitness-timer

iPhoneのホーム画面にアプリとして追加して使う、運動メニュー用タイマー。2つのHTMLファイルがそれぞれ独立したアプリ。

## 使い方

1. Safariで各ファイルのURLを開く
   - `https://ussy1110.github.io/fitness-timer/strength-timer.html`
   - `https://ussy1110.github.io/fitness-timer/night-routine.html`
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから起動

## ファイルを更新するとき

1. GitHubで対象ファイルを開き、右上の鉛筆アイコンで編集
2. 中身を新しい内容に貼り替えて「Commit changes」
3. ホーム画面のアイコンは自動で最新にならないことがあるため、一度アイコンを消してSafariで開き直し、「ホーム画面に追加」をやり直すと確実

## strength-timer.html（火木・筋トレ20分）

BBレベル（通常／軽め／ストレッチのみ）を選ぶと、種目とセット数が自動で切り替わる。

### 変更履歴
- **v1.0.0** — 胸椎モビリティ・コア・上半身・下半身の固定メニューとタイマーの初版
- **v1.1.0** — 心拍アップ・バランスのフェーズを追加、下半身にランジ・ヒップヒンジを追加
- **v1.2.0** — 上半身・下半身を「一連の動きを1セットとして2セット、間にインターバル」の構成に変更
- **v1.3.0** — 下半身の締めくくりに相撲スクワットを追加
- **v1.4.0** — 種目名を音声で読み上げる機能を追加（既定はOFF、開始前トグルで切り替え・設定を記憶）
- **v1.5.0** — 読み上げの速度・句読点を調整して自然な発話に、バージョン表示を追加
- **v1.6.0** — 実行中に画面がスリープしないようWake Lockを追加
- **v1.6.1** — 開始前画面に「5kgダンベルと水を準備」のリマインダーを追加
- **v1.7.0** — BB数値の3段階判定（BB50/35/34）を廃止し、自覚症状ベースの2択（通常／自覚症状あり）に変更
- **v1.8.0** — 別チャットで指示済みだった変更を統合：Garmin確認バナー追加、その場マーチ→ジャンピングジャック、ダンベルロウを左右分割・30秒・四つ這いフォームに変更、下半身に5秒インターバル追加（ランジ→グルートブリッジ、グルートブリッジ→相撲スクワット）

## night-routine.html（夜のストレッチルーティン）

BBレベルの区別なし。毎晩同じ内容を順番通りに行う。ストレッチポール→呼吸→90/90→股関節・胸椎モビリティの順で、終了後はLifenoteでのジャーナリングへ案内。

### 変更履歴
- **v1.0.0** — 実施順に沿ったタイマーの初版（鎮静系の暗めデザイン）
- **v1.1.0** — 90/90ストレッチなど、機械的に20分へ合わせていた時間配分を自然な長さに修正
- **v1.2.0** — 文字サイズを拡大
- **v1.3.0** — 音声読み上げ機能を追加、発話を自然な速度に調整、バージョン表示を追加
- **v1.4.0** — 実行中に画面がスリープしないようWake Lockを追加
